Programming languages, a brief overview

Programming languages give computers instructions to perform specific tasks.

Types of Languages

  • High-Level Languages : These languages are easier to read! Like Python and Java
  • Low-Level Languages: These languages are closer to the hardware! Like C and Assembly

How does each run the code given?

  • Compiled:The instruction code is translated into machine code first before running. An Example would be like Java! It compiles to bytecode for the Java Virtual machine.
  • Interpreted:The instruction code runs line-by-line like in Python!
